# DITING 2.8.0

## 更新内容

- 中性色工作台、深浅主题、移动导航和键盘焦点入口。
- 总览使用全量口径摘要；数据源独立刷新，隐藏页面暂停新请求。
- 长会话保留完整历史、定位与底部跟随，减少屏幕外布局。
- 资产图支持全节点搜索、分页、折叠组键盘操作、缩放及手动位置保留；读取失败保留旧图。
- 资产表格保留服务端分页，失败状态不冒充空列表；尊重减少动画偏好。

## 数据与升级

新建数据库不预置模型或业务数据；截图仅为合成展示记录，不导入应用。连接已有数据库保留已有记录。

包名与 Windows 解压根目录统一使用 DITING，包内 artex.exe 和 ARTEX_* 环境变量保持兼容。旧更新器只识别 artex 附件时，请手动下载。升级前制作完整加密备份；数据库迁移后回退需要恢复升级前备份。

Docker 部署包使用 diting:2.8.0-local。PostgreSQL 16.15 镜像复用 2.7 的共享附件，只保留一份；SHA256SUMS 包含共享镜像条目。源码使用发行页自动 Source code 下载，不重复上传源码 ZIP。
