# DITING 2.8.0

## 更新内容

- 中性色工作台、深浅主题、移动导航和键盘焦点入口。
- 总览改用全量口径摘要，数据源独立刷新，隐藏页面暂停新请求。
- 长会话减少屏幕外布局，保留完整历史、定位和底部跟随。
- 大型资产图支持全节点搜索、分页、折叠组键盘操作、缩放和适应画布，刷新时保留手动位置。
- 资产表格保留服务端分页；读取失败保留旧内容，避免误报为空列表。
- 减少动画偏好生效，保留运行状态标识。

## 安装、升级与数据

新建数据库不预置模型或业务数据；README 截图仅使用合成展示记录。连接已有数据库保留已有记录，不会清空。

Windows 包统一为 DITING-2.8.0-windows-amd64.zip，包内 artex.exe 保留兼容名。历史更新器只识别 artex 附件时，需要手动下载安装；本次不把后续版本的更新器改动合入 2.8。

升级前按 DATA_AND_BACKUP.md 制作完整加密备份；数据库迁移后回退需要恢复升级前备份，不能只替换旧二进制。镜像配套部署包使用 diting:2.8.0-local 标签，PostgreSQL 16.15 镜像复用 2.7 发行的共享附件，SHA256 相同。

## 验证范围与镜像来源

保存的 2.8 基线已通过 Windows 空库、2.7 升级、鉴权/历史重启与数据库转储恢复、Docker Desktop Linux amd64 空卷及重建检查；本次发布另核对源码、程序、镜像各层与空白首次安装。程序和公开源码业务内容按原 2.8 基线核对；公开历史不包含后续开发。

镜像保留已验收的 2.8 应用及既有运行层，本机 Docker 引擎当前不可用，本次没有重新运行容器。独立 Linux/macOS 宿主和其他架构未实际验收。真实模型与靶场验收已按用户要求取消，不计为通过；本次不调用模型或目标。

详见 INSTALLATION.md、DEVELOPMENT.md 与 DOCKER_BACKUP.md。源码使用发行页自动 Source code 下载，不重复上传手工源码 ZIP。
